## Architecture

- ArcWorldItem: ERC-721 NFT for game items (weapons, armor, pets, skins). Minters list controlled by owner.
- ArcWorldMarketplace: NFT marketplace for listing/buying ArcWorldItem NFTs with USDC. 2.5% fee. Approval-based pull pattern (no escrow custody). Owner = platform deployer.
- ArcWorldQuest: Quest system with USDC rewards. EIP-712 owner-signed completion attestation required to claim. Owner = platform deployer.

## Frontend

- 3D World: React Three Fiber (src/game/World.tsx), Player controls (WASD + mouse look), QuestZone, ItemPickup
- UI: WalletBar, HUD, Inventory modal, Marketplace modal, QuestBoard modal
- Chain: Arc Testnet (chain ID 5042002)
